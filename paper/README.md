# Optimizing Age of Incorrect Information on Real-World IoT Sensor Datasets

ICC 2027 (IoT track) submission. Authors, affiliations and the target page limit are in `paper.tex` and `CLAUDE.md`.

Build: `make` (paper, IEEEtran, biber), `make slide` (companion deck), `make clean`, `make view`.

- `paper.tex`, `paper.bib`, `paper.sty`: source, bibliography and preamble
- `slide.tex`, `slide.sty`: companion deck
- `figure/`: figure PDFs, images and TikZ sources used by the paper and deck
- `response-round1.md` to `response-round3.md`: responses to the review rounds
- `TODO.md`: remaining work
- `CLAUDE.md`: writing rules
